# Soft Miniature — bản duyệt UI

Mở `index.html` để duyệt 6 màn hình, các tab Garage và popup.

Bố cục và dữ liệu minh họa lấy từ `../layout-review.html`: HUD và 5 tab cố định, nội dung cuộn. Nâng cấp một cột; Túi 3 cột; Tay đua 2 cột; Garage có Xe / Phụ tùng / Ngoại hình; Shop có đầy đủ nhóm và gói mua.

Đây là prototype riêng để duyệt thiết kế, chưa tích hợp vào game. Đường đua dùng hình minh họa cắt bằng CSS từ concept; các nút chỉ thay đổi trạng thái demo, không mua hàng hoặc ghi tiến trình.

Assets mới do built-in ImageGen tạo: icon clay, 12 chân dung và 6 xe. Prompt gốc được lưu trong `assets/generation.json` và `assets/extra-generation.json`.

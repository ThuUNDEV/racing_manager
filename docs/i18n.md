# Đa ngôn ngữ (i18n)

Lõi: `core/i18n.gd` (class `I18n`). Bảng dịch: `i18n/<code>.json` = `{"id": "chữ"}`.

## Ngôn ngữ

| Mã | Tên | Dấu thập phân | Font |
|---|---|---|---|
| `en` | English (gốc, fallback) | `.` | Roboto |
| `vi` | Tiếng Việt | `,` | Roboto |
| `id` | Bahasa Indonesia | `,` | Roboto |
| `ms` | Bahasa Melayu | `.` | Roboto |
| `th` | ไทย | `.` | NotoSansThai* |
| `ja` | 日本語 | `.` | NotoSansJP* |
| `ko` | 한국어 | `.` | NotoSansKR* |
| `zh_Hans` | 简体中文 | `.` | NotoSansSC* |

\* Font bổ sung đọc từ `assets/fonts/NotoSans{Thai,JP,KR,SC}-Bold.ttf` và gắn làm fallback cho Roboto
(font của ngôn ngữ đang chọn đứng đầu, vì chữ Hán Nhật/Trung khác nét). **Chưa có tệp nào trong repo**:
lúc này game dựa vào font hệ thống (`allow_system_fallback`), chạy được trên Android/iOS/PC nhưng **bản web
sẽ hiện ô vuông** cho th/ja/ko/zh. Thêm tệp đúng tên là game tự dùng, không cần sửa code. Nên cắt font
(pyftsubset) chỉ giữ ký tự có trong `i18n/*.json` để nhẹ.

Lần đầu mở game: theo ngôn ngữ máy (`I18n.detect(OS.get_locale())`, `zh_TW` → `zh_Hans`, `in` → `id`,
ngôn ngữ khác → `en`). Người chơi đổi trong Cài đặt → Ngôn ngữ (popup lưới 2 cột). Đổi là áp dụng ngay:
game lưu tiến trình rồi chạy lại màn loading. Lựa chọn lưu ở `user://language.cfg`.
Biến môi trường `RM_LANG=<mã>` ghi đè (test chạy `vi` vì assert dùng câu tiếng Việt).

## Dùng trong code

```gdscript
label.text = I18n.t("shop.claim")
label.text = I18n.t("main.level") % lv                    # placeholder %d/%s giữ ĐÚNG THỨ TỰ như bản en
label.text = I18n.tn("shop.days", n) % n                 # số ít: khóa "shop.days.one" (chỉ en chia)
const TAB_NAMES := ["main.race_2", "main.upgrades"]      # bảng const giữ ID, dịch ở chỗ dùng: I18n.t(TAB_NAMES[i])
```

- ID: `<khu>.<tên>` (`shop.`, `main.`, `garage.`, `drivers.`, `common.` cho chữ dùng nhiều nơi,
  `data.<tệp>.` cho chữ trong data JSON). Thiếu khóa ở một ngôn ngữ → lấy `en` → trả chính ID.
- Data JSON: chuỗi hiển thị viết dạng `"@data.cars.pico_lightning"`; `GameData._load`, `Tutorial` và
  `ShopPackUi.recipe` dịch lúc nạp và tự nạp lại khi `I18n.revision` đổi. Ghi chú dev (`_doc`, `note`) để tiếng Anh thường.
- Lỗi kiểm tra data, log, push_error: viết tiếng Anh thường, **không** đưa vào bảng dịch.
- Không so sánh chữ đã dịch trong logic (dùng id/cờ). Chữ mặc định lưu vào save (tên đội) nhận lại bằng
  `I18n.is_any_translation("save.team", text)`.
- Số: dùng `Balance.fmt_*` / `I18n.dec()`, không viết cứng dấu thập phân.

## Thêm chuỗi

1. Thêm khóa vào `i18n/en.json` (và `vi.json`) rồi dùng `I18n.t("khu.ten")`.
2. `python -X utf8 tools/i18n_check.py` báo khóa thiếu, lệch placeholder (theo thứ tự), xuống dòng lệch,
   chữ Việt còn sót trong code/data. `--missing ja` in các khóa ja còn thiếu kèm bản tiếng Anh để gửi dịch.
3. Điền các ngôn ngữ còn lại; `tests/i18n_test.gd` chặn thiếu khóa/lệch placeholder.

## Thêm ngôn ngữ

Thêm `i18n/<code>.json` đủ khóa, một dòng trong `I18n.LANGS` (tên tự xưng, dấu thập phân, nhóm font),
mã máy trong `I18n.detect` nếu cần, font trong `_FONT_FILES` nếu là chữ ngoài Latin/Việt.
`tests/league_redesign_preview_test.gd` dựng trang Giải ở mọi ngôn ngữ để bắt chữ tràn khung.

## Chưa làm

- Placeholder theo tên/đổi chỗ (`{0}`): bản dịch phải giữ thứ tự `%s/%d` như tiếng Anh.
- Ảnh có chữ in sẵn (asset IAP/UI) chưa có bản theo ngôn ngữ.
- Font CJK/Thái chưa đóng gói (xem trên).

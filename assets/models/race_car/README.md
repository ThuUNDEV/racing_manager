# Soft Miniature cars v4

Original code-generated geometry and materials. No third-party meshes, textures,
logos, or assets from `Design/References/RaceStar_Garage_Extract/` are used.

| Game data `class` | Family / scene | Silhouette |
| --- | --- | --- |
| 1 | `pico.tscn` | Short rounded city hatch, domed canopy, round headlights, compact wing |
| 2 | `nova.tscn` | Longer coupe, lower canopy, small rear wing |
| 3 | `apex.tscn` | Wide, low sports GT with wing |
| 4 | `titan.tscn` | Broad muscle GT, raised shoulders, twin hood vents |
| 5 | `zenith.tscn` | Long, low hypercar, side intakes, broad wing |

Each family serves its three existing stat variants, selected from `GameData.car(id).class`.
No balance data or save format changes. Garage selects all five; racing still loads
`race_car.tscn`, the Pico-compatible default, until its separate integration is authorized.
`race_car.glb` exports the same default for external inspection.

- Front: -Z; up: +Y; tire contact plane: Y=0.
- Rounded boxes have indexed geometry, smooth analytic normals and sloping canopies.
- Tires, recessed rims, five rim slots, hubs, tread rings, lenses, mirrors, handles,
  bumpers and class-specific details are all generated by the builder.
- Clay/plastic paint, blue glazing, warm satin alloy and rough rubber use native PBR
  materials; no bitmap texture maps are required.
- `Body_Paint_Blue` is retained for all recolourable body panels, roof, mirrors,
  wings and hubs. Duplicate it per instance before recolouring.
- Garage livery duplicates the actual `Body` and `Roof` meshes with a masked spatial
  shader, so stripes/checkers follow domed surfaces. Lightning also appears on both
  doors. `decal_surfaces` is retained only as legacy metadata.
- `body_width`, `body_top`, `body_length` place code-built Garage door badges.
  Numbers are catalogue index + 3 (03–17); no saved cosmetic field is added.
- Clearcoat paint, sky reflection, rounded torus tires, contrast accents and larger
  circular lenses replace v3 details. The five families have distinct proportions.
- `wheel_track` and `wheel_base` metadata locate Garage contact shadows.
- No collision, vehicle controller or wheel animation is provided.

Rebuild deterministically:

```sh
godot --headless --path . -s res://tools/models/build_race_car.gd
```

Preview/cosmetic regression and real Vulkan captures (isolated save):

```sh
XDG_DATA_HOME=$(mktemp -d) RM_LANG=vi godot --path . --screen 1 --audio-driver Dummy -s res://tests/garage_car_preview_test.gd -- --economy-test
```

plus Garage tabs at 390 and the existing 320/390/412 framing checks.

`ui/car_livery.gdshader`. Dynamic badges/livery remain in Garage; race still loads
the valid generated default geometry without changing its renderer integration.

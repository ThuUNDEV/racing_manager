# UI font

Roboto Bold is bundled from https://github.com/googlefonts/roboto-2/tree/main/src/hinted (Roboto-Bold.ttf). License: Apache 2.0, see LICENSE.txt.

Used by HdUi for actual bold letterforms and Vietnamese coverage. This is a visual approximation of the approved raster demo; its original typeface was not supplied. No synthetic emboldening or horizontal compression.

Roboto Black Italic (`Roboto-BlackItalic.ttf`) from the same source is used only for racing section ribbons. It provides native heavy italic letterforms and Vietnamese glyphs under the same Apache 2.0 license. The source typeface of the raster reference remains unidentified.
